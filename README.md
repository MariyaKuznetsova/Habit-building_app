# Проект приложения по созданию привычек

## Описание:

Проект платформы по созданию привычек

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/pythonproject14.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. В приложении вы можете создать привычки с указанием места, времени, периода, добавить вознаграждения, поставить время выполнения.
2. В приложении есть телеграм бот котрый будет отправлять напоминание когда нужно выполнить привычку.
3. В приложении если вы можете посмотреть публичные привычки.
4. Редактировать, удалять, просматривать можно только свои привычки.
